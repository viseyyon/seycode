## What is SeyCode?

**SeyCode** is the next-generation open source AI coding agent, rebranded and rearchitected from OpenCode with revolutionary features that make it objectively better than Claude Code.

## 🌟🌟 The Two Killer Features

### 1. Automatic Prompt Engineering

**Killer Feature #1:**

Every prompt you write is **automatically optimized** using advanced prompt engineering techniques BEFORE execution:

```
You type: "fix this bug"

SeyCode transforms it to:
"Investigate [specific bug] in [component/file]:

1. @architecture-explorer - Understand the affected area
2. @debug-helper - Setup debugging environment
3. Identify root cause through debugging
4. Implement fix following AGENTS.md style guide
5. @test-generator - Add regression tests
6. @test-runner - Verify fix with tests
7. @code-reviewer - Review implementation

Expected outcome: Bug fixed, tested, and reviewed."
```

**Result**: Better outcomes, faster development, nothing forgotten, perfect prompts every time.

### 2. Automatic Memory Management & Checkpoints

**Killer Feature #2:**

Every action automatically creates checkpoints enabling perfect resume and rollback:

```
You perform actions:
- Edit file → Auto-checkpoint
- Run tool → Auto-checkpoint
- Invoke skill → Auto-checkpoint

Something goes wrong:
@memory-manager rollback

Want to try different approach:
@memory-manager branch "alternative"

Need to resume after interruption:
@memory-manager resume last
```

**Result**: Never lose work, experiment fearlessly, perfect recoverability, complete peace of mind.

## 🏗️ Architecture

SeyCode is built on three revolutionary principles:

1. **Skill-First Development** - Every common task has an executable skill
2. **Agent Specialization** - Right agent, right permissions, right task
3. **Quality by Design** - Built-in review, audit, and validation

### Architecture Diagram

```
User Input
    ↓
@prompt-engineer (AUTOMATIC)
    ↓
Enhanced & Optimized Prompt
    ↓
@workflow-orchestrator (if needed)
    ↓
Skill Chain with Quality Gates
    ↓
Specialized Agents
    ↓
Tool Execution
    ↓
Automated Quality Checks
    ↓
Perfect Result
```

## 🌐 Architecture Highlights

### Client/Server Split
- **Server**: Hono-based HTTP server (port 4096)
- **Clients**: TUI, Web UI, Desktop app, or external via ACP
- **Communication**: REST API with SSE for real-time updates

### Core Components
- **Session Management**: LLM streaming with tool invocation
- **Agent System**: Build, plan, general + 9 specialized agents
- **Tool Registry**: Dynamic tool discovery and execution
- **LSP Integration**: Multiple language servers
- **MCP Support**: Model Context Protocol integration
- **Plugin System**: Extensible via plugins and hooks
- **Skill System**: Executable workflow documentation

### Data Layer
- **SQLite** via Drizzle ORM
- **Event Bus** for pub/sub communication
- **Instance State** for per-directory isolation
- **Skill Cache** for performance

## 🔐 Security

- **Permission-based agent system** - Fine-grained control
- **Built-in security auditor** - Automatic reviews
- **Input validation** - Zod schemas everywhere
- **Audit logging** - All actions tracked
- **Sandboxed execution** - Isolated environments
