## 📝 Documentation Standards

### File Naming
- Use `UPPER_CASE.md` for top-level docs
- Use `lowercase-with-dashes.md` for subdirectory docs
- Use `.md` extension for all markdown files

### Content Structure
- Start with clear title and description
- Include table of contents for docs > 200 lines
- Use emoji sparingly and meaningfully
- Include code examples where appropriate
- Add cross-references to related docs

### Markdown Style
- Use ATX-style headers (`#`, `##`, `###`)
- Use fenced code blocks with language tags
- Use tables for structured data
- Use lists for sequential/grouped items
- Use callouts for important notes (> [!NOTE], > [!TIP], etc.)
